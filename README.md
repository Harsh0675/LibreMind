# 🧠 LibreMind

A polished, lightweight, offline Android memory matching game.

## Features
- Classic, Time Rush and Zen modes
- Multiple board sizes
- Combo scoring
- Timer, moves and score
- Smooth, simple Android UI
- No account, ads or network permission
- Open-source friendly

## Build
Open the project in Android Studio and build the `app` module.

Application ID: `com.libremind.game`
Version: `1.0`
